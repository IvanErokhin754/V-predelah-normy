Сюда кладётся эмбиент: ambient.wav

Формат: WAV, PCM 8/16/24/32 бит или 32-bit float, моно или стерео, любая частота
(игра сама пересчитает в 44100 Гц). Файл играет по кругу.

Из MP3, OGG, FLAC и т. п.:
    ffmpeg -i мой_эмбиент.mp3 ambient.wav

После замены файла пересоберите проект (cmake --build build) — CMake копирует
папку data рядом с игрой — или положите файл сразу в build/data/audio/.
Громкость: Настройки → Эмбиент.
