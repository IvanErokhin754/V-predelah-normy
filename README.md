# В пределах нормы — прототип 0.1

Одиночный 3D-хоррор от первого лица по ТЗ `22880831-game-design-spec.md`.
C++17, SDL2, OpenGL 3.3 core. Текстуры, звук и геометрия создаются кодом —
в репозитории нет ни одной картинки или звукового файла.

## Сборка и запуск

### macOS

```bash
brew install cmake sdl2
cmake -S . -B build
cmake --build build -j
./build/norma
```

### Linux

```bash
sudo apt install cmake g++ libsdl2-dev
cmake -S . -B build && cmake --build build -j
./build/norma
```

Тесты ядра (графика не нужна):

```bash
./build/norma_tests data/balance.ini      # или: ctest --test-dir build
```

Если CMake не находит SDL2, укажи библиотеку вручную:
`cmake -S . -B build -DSDL2_LIBRARY=/opt/homebrew/lib/libSDL2.dylib`.

## Управление

| Ввод | Действие |
|---|---|
| W / A / S / D | Идти |
| Мышь | Осматриваться; у монитора — курсор |
| E | Взаимодействие: терминал, койка, кнопки смены, табличка |
| ЛКМ | Выбрать ответ на экране терминала |
| 1 / 2 / 3 | Выбрать ответ с клавиатуры |
| Enter | Подтвердить ответ; пока текст печатается — показать его целиком |
| R | Повторить запись голоса (задание «Пустой сектор») |
| Esc | Отойти от терминала (прогресс теста сохраняется); в сцене — пауза |

Клавиши привязаны к физическому положению (скан-кодам), поэтому работают и при
русской раскладке.

## Параметры запуска

```
--dev            режим разработчика (см. ниже)
--fullscreen     на весь экран          --windowed    принудительно в окне
--size 1600x900  размер окна            --seed N      зерно новой игры
--data ПУТЬ      папка с balance.ini    --nosave      не трогать сохранение и настройки
--script ФАЙЛ    сценарий автотеста (только с --dev)
```

## Режим разработчика (`--dev`)

Без `--dev` ни рейтинг, ни результат утренней проверки, ни отладочные клавиши
в игре недоступны.

| Клавиша | Действие |
|---|---|
| Tab | Табло: день, рейтинг, диапазон, исход утра, этап дня |
| `[` / `]` | Рейтинг −5 / +5 |
| 5 / 6 | Рейтинг 20 / 21 — нижний порог с обеих сторон |
| 7 / 8 | Рейтинг 79 / 80 — верхний порог с обеих сторон |
| 9 | Принудительно включить освобождение на следующем рассвете |
| 0 | Сразу закончить день (маршрут следующего утра — по текущему рейтингу) |
| − | Закрыть задания дня без начисления очков |

Как проверить концовки:

- **«Рабочее назначение отменено»** — `5`, затем `0`.
- **«Вас ожидает индивидуальное собеседование»** — `8`, затем `0`.
- **Хорошая** — `9`, затем `0`.
- **Подтверждение номера у двери** — `6`, `0`. **Дополнительное наблюдение** — `7`, `0`.

Клавиши работают в 3D-сцене (не у монитора). На Mac цифры и скобки — обычные клавиши, Fn не нужен.

## Баланс

Все очки, пороги, шанс освобождения и период смен лежат в `data/balance.ini`
и читаются при запуске — пересборка не нужна. Если в файле ошибка, игра назовёт
строку в главном меню и возьмёт значения по умолчанию.

## Устройство проекта

```
src/core/      ядро правил, чистый C++17 без зависимостей
  balance      значения баланса, чтение balance.ini, применение эффекта, диапазоны
  tasks        задания А/Б/В, смены, перемешивание ответов, связки заданий
  game_state   день, скрытый рейтинг, рассвет (2%), маршрут утра, сохранение
  rng.h        детерминированный генератор (одинаковые задания на любой платформе)
src/engine/    движок
  sdl_min.h    объявления SDL2 (только то, что используется)
  gl_min       загрузчик функций OpenGL 3.3
  renderer     меши, свет, 2D-слой, рендер в текстуру, эффект ЭЛТ
  texgen       процедурные текстуры трёх плотностей пикселя
  font         пиксельный шрифт 8x16 с кириллицей
  audio        синтез всех звуков и микшер
src/game/      игра
  level        план комплекса (текстовая сетка), геометрия, коллизии, двери, свет
  terminal     экран монитора: задания, печать, выбор и подтверждение
  game         цикл дня, конвоир, смены, концовки, меню, режим разработчика
tests/         тесты ядра (12 900 проверок, включая пример из раздела 7 ТЗ)
tools/         gen_font.py — запекание шрифта из GNU Unifont (Python + Pillow)
data/          balance.ini
```

Ядро ничего не знает о графике: терминал и физические кнопки смены вызывают одни
и те же `confirmAnswer` / `confirmShiftAction`, поэтому очки считаются по одним
правилам, а повторное подтверждение ядро просто отклоняет.

Уровень задаётся сеткой символов в начале `src/game/level.cpp` — клетка 1×1 м.
Перепланировку можно начинать с неё.

## Что сделано сверх буквы ТЗ и где принято решение за ТЗ

- **Связка заданий.** «Связка двух вариантов» понимается как неупорядоченная пара
  вариантов; у задания А два варианта (по приказу). Всего связок пять, вчерашняя
  исключается из выбора.
- **Сохранение.** Пишется на рассвете и после каждого подтверждения. Хранит исход
  утра, зерно дня и прогресс, поэтому выход и «Продолжить» не дают ни переиграть
  ответ, ни перебросить 2%. После любой концовки сохранение стирается. Файл
  нечитаем в блокноте, чтобы рейтинг не подсматривали.
- **Смена «сигнал».** Кнопка «Запрос связи» — это и есть «ответить на стук»: одно
  действие, после него из-за двери стучат в ответ. После «Сигнала нет» стук
  раздаётся ещё раз, а в отчёте смены его нет.
- **Числа в заданиях** меняются каждый день: номер пленного на карточках, сектора,
  показания прибора (цифры в журнале переставлены), номера пломб.
- **Свет под дверями и лампы над ними** показывают маршрут: в обычное утро горит
  холодная лампа над проходом к тестам, в плохое — красная над другой дверью.
- **Речь** комплекса и конвоира — синтетический звук плюс субтитры; озвучки нет.

## Сценарные прогоны

В `tests/scenarios/` лежат сценарии, которыми проверялась игра: полный обычный
день (камера → терминал → два ответа → обратно → койка → утро второго дня),
обе смены, все пять исходов утра и обе концовки. Каждый сценарий печатает строки
`STATE …` с днём, рейтингом и фазой и сохраняет кадры в `scenario_shots/` (формат PPM).

```bash
mkdir -p scenario_shots
./build/norma --dev --nosave --seed 11 --script tests/scenarios/day.txt
```

Зерно `--seed 11` важно для `seal.txt` и `signal.txt`: без него новая игра
с шансом 2% может начаться с освобождения, и до смены сценарий не дойдёт.

## Чего нет и что не проверено

- Проверено на Linux (GCC 13 и Clang 18, программный OpenGL Mesa): сборка, тесты
  ядра, сценарные прогоны полного дня, обеих смен и всех концовок.
  **На macOS и Windows сборка не запускалась.** Код написан с расчётом на macOS
  (контекст 3.3 core с forward-compatible, Retina через размер drawable), но первый
  запуск на Mac — это проверка, а не формальность.
- Сборка с системными заголовками SDL (`-DNORMA_SYSTEM_SDL_HEADERS=ON`) не
  проверялась: в среде разработки заголовков SDL не было. По умолчанию используются
  встроенные объявления из `sdl_min.h` — именно этот путь протестирован.
- Геймпад, переназначение клавиш, локализация — вне ТЗ прототипа.
- Баланс — стартовый, из ТЗ. Плейтеста не было.
